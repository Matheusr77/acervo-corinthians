# Escudos

Coloque aqui o escudo de cada time com o **id_time** como nome do arquivo:

- `1.png` → Corinthians
- `102.png` → Palmeiras
- `425.png` → São Paulo

Formatos aceitos: `.svg`, `.webp`, `.png`, `.jpg`. Tamanho recomendado: 256×256 px, fundo transparente.

Para descobrir o id de um time, abra a página dele no site: o número no endereço é o id
(ex.: `/adversarios/102`).

O comando `npm run escudos` baixa automaticamente os que existirem no Wikidata. Veja o README.
